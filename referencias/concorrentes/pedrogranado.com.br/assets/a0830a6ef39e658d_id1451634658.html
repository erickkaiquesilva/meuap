Pedro Granado Permite o acesso para proprietários, locadores, locatários e fiadores. Permite notificações por PUSH. Para os proprietários Acesso aos documentos, ocorrências, ações comerciais, alterações cadastrais, criar promoções para seus imóveis, informe de rendimento, prestação de contas dentre outros. Para os locadores Acesso ao analítico do aluguel, extrato, ocorrências, documentos, alterações cadastrais, prestação de contas dentre outros. Para os locatários Acesso ao analítico do aluguel, boleto, documentos, ocorrências, alterações cadastrais dentre outros. Para os fiadores Acesso ao analítico do aluguel, boleto, documentos, ocorrências dentre outros.
